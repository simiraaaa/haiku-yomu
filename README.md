# haiku-yomu

*俳句詠む 弦の調べの 五月雨に*

[English version](./README.en.md)

Haiku にドキュメントを読んでもらい**深く考えなくても理解できる**かを検証する Claude Code 用スキル (プラグイン)。

あえて推論量を絞った読み手に読ませることで、「深く推論できる読者なら穴を補って読めてしまう」問題を避け、資料単体の分かりやすさを測る。

## インストール

Claude Code のセッションで、以下を **1 つずつ順に**実行する (まとめて貼り付けると 2 行目以降が正しく実行されないことがある):

1. マーケットプレイスを登録する

   ```
   /plugin marketplace add simiraaaa/haiku-yomu
   ```

2. プラグインをインストールする

   ```
   /plugin install haiku@haiku-yomu
   ```

3. 同じセッションでそのまま使う場合はリロードする (新しいセッションなら不要)

   ```
   /reload-plugins
   ```

これで日本語資料用の `haiku:yomu` と英語資料用の `haiku:retell` の両方が入る。

## 使い方

Claude Code のセッションで:

- `/haiku:yomu` と入力する(どのファイルか指定することもできる)
- または「この資料分かりやすい?」「Haiku にレビューさせて」「軽量モデルで読解チェックして」と頼む

*注意: スキルを実行するセッションでは、推論力があるモデル(Opus 等)を使用しないと成立しない*

1. 本体のセッションがファイルの内容を確認
2. Haiku が読解したものを突き合わせる
3. ズレと修正案の報告
4. ユーザーが修正するか判断する(スキルは報告で止まる)
5. 修正を依頼した場合は、再度 2〜4 を行う (意図は使い回し、Haiku には毎回まっさらに読み直させる)

同梱の `haiku-read.sh` で読解の実行部だけを直接使うこともできる:

```bash
./skills/yomu/haiku-read.sh <資料ファイル> "<前提知識テキスト (省略可)>"
```

(リポジトリ root から実行する場合の例。プラグインとしてインストール済みならスキルが場所を解決する)

## 仕組み

1. **本体セッションが先に「正解」を言語化する** — 要点 (3〜5 個) と読後の行動
2. **隔離した Haiku に資料本文だけを渡し、要点を自分の言葉で再現させる** — ツールなし・カスタマイズなし・low effort
3. **再現と正解のズレを見る** — 誤解・欠落がそのまま資料の分かりにくさとして表面化する

### 補足

Haiku に「分かりにくい箇所を指摘して」と直接頼むと、「分かりやすいです」と返しがちで検証にならないためこの仕組みを採用している。

誤読がある場合は、**資料側の問題として扱う**。

## 使いどころ

- README・設計資料・手順書・スキル定義・PR 説明文などの**説明系テキスト**
- 「読者に何かを理解させたい文章」なら手順書でなくてもよい (技術ブログ・共有メモなど)
- 複数資料は並列で検査できる (詳細は SKILL.md)
- **資料の言語に合わせてスキルを選ぶ**: 日本語の資料は `haiku:yomu` (レポートも日本語)、英語の資料は `haiku:retell` (レポートも英語)。言語が違っても動くが、報告内容が粗くなることがある

## 検出できないもの

- **内容の正しさ・網羅性** — Haiku は資料の外を知らない
- **他の資料・実装との整合** — 各検査は対象の本文しか読まない
- **面白さ・文体・説得力** — 測るのは「意図が伝わるか」だけ

合格が示すのは「**指定した前提のもとで、Haiku が要点・読後の行動を再現できた**」ことまで。

## 構成

| ファイル | 役割 |
|---|---|
| `skills/yomu/SKILL.md` | スキル本体 (手順・判断基準・Red Flags) |
| `skills/yomu/haiku-read.sh` | 読解実行の primitive (プロンプト組み立て + 隔離した Haiku の起動) |
| `skills/retell/` | 英語資料用スキル `haiku:retell` (SKILL.md + haiku-read.sh の英語版) |
| `.claude-plugin/plugin.json` | プラグイン定義 (plugin 名 `haiku`) |
| `.claude-plugin/marketplace.json` | 配布用マーケットプレイス定義 (marketplace 名 `haiku-yomu`) |
